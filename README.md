# PVG College Auth & Enterprise Management System 🎓

A professional-grade, unified authentication, authorization, and administrative suite built for **PVG College of Science**.

**Technology Stack:** React (Vite) · FastAPI · PostgreSQL · SQLAlchemy · Glassmorphism UI

---

## 🚀 Master Setup & Quick Start

The fastest way to launch the entire ecosystem (Backend, Frontend portals, and Ngrok tunnels) is to use the master startup script:

```powershell
# Run the master startup sequence from the root directory
.\start_all.ps1
```
This script will automatically free ports `8000` and `5173`, and launch the FastAPI server, the React portals, and Ngrok dual-tunnels in separate PowerShell windows.

---

## 🗄️ Database Setup (PostgreSQL)

The system uses a **PostgreSQL** database named `pvg_auth` running on port `5432`.

### **Importing the Full Database Dump**
To avoid manual table creation and empty datasets, the database dump containing the **full schema and initial seed data** (modules, permissions, roles, test users, and students) is provided in `database_scripts/pvg_auth_full_dump.sql`.

1. Create the database in PostgreSQL:
   ```sql
   CREATE DATABASE pvg_auth;
   ```
2. Import the dump file:
   ```bash
   psql -U postgres -d pvg_auth -f database_scripts/pvg_auth_full_dump.sql
   ```

## 💻 Manual Startup Commands

If you prefer to run services individually, use these commands from the root directory:

### **1. Start the Python Backend**
```powershell
cd backend
# Set up a virtual environment and install dependencies
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt

# Start the development server
.\venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

### **2. Start the React Frontends**
```powershell
# Install Node modules for the portals
npm install

# Start both Admin (port 5173) and User (port 5175) dev servers
npm run dev:frontend
```

### **3. Start Ngrok Tunnels**
```powershell
# Run the local ngrok executable with the configured dual-tunnel settings
.\ngrok_bin\ngrok.exe start --all --config=ngrok_dual.yml
```

## ⚙️ Environment Configuration

Ensure a `.env` file is created in your `backend/` folder:

```env
DATABASE_URL=postgresql+psycopg2://postgres:YOUR_PASSWORD@localhost:5432/pvg_auth
JWT_SECRET=6950526b1649fdd3c7e15d430812376a2c775156cc9510cefd8c4dc9e9d69e5a
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60
```

> [!IMPORTANT]
> Keep the `JWT_SECRET` identical across all ERP modules (SIS, Placement, Fees, etc.) so that they can decode the tokens generated by this Auth system.
